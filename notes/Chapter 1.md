## 一、类的定义与访问限定符

在 C++ 中，**类**是自定义类型，用来描述一类事物的**属性（成员变量）**和**行为（成员函数）**。

```cpp
// 定义一个类
class Person
{
public:
    void Print();        // 成员函数（行为）

private:
    char* _name;         // 成员变量（属性）
    int _age;
};
```

### 1.1 访问限定符

| 限定符 | 访问权限 | 说明 |
| --- | --- | --- |
| public | 公有 | 类内外均可访问 |
| private | 私有 | 只能在类内访问 |
| protected | 保护 | 类内及派生类可访问（继承章节详解） |

**使用习惯：**

- 成员变量放在 `private` 下（保护数据，体现封装）；
- 成员函数放在 `public` 下（对外提供接口）；
- 成员变量命名统一加前缀 `_` 或以 `m` 开头，与局部变量区分。

### 1.2 类的声明和定义分离

将类的**声明**放在头文件（.h），成员函数的**定义**放在源文件（.cpp）。注意：只有"类内定义"才算内联，声明和定义分离书写不属于内联。

```cpp
// Person.h —— 声明
class Person
{
public:
    void Print();

private:
    char* _name;
    int _age;
};

// Person.cpp —— 定义
#include "Person.h"

void Person::Print()
{
    // 函数体
}
```

### 1.3 类形成了一个新的域

定义类之后，类名就是新的类型，类中的成员属于类域，类外通过 `类名::成员` 访问，例如 `Person::Print`。

### 1.4 struct 和 class

C 语言中的 struct 只是结构体；C++ 中 struct 被**升级成了类**。struct 和 class 都可以定义类，区别仅在于默认访问权限：

```cpp
struct Student
{
    int _id;    // struct 默认访问权限：public
};

class Teacher
{
    int _id;    // class 默认访问权限：private
};
```

**区别：** struct 默认 public，class 默认 private，其余用法完全一致。

## 二、类的实例化：对象与内存

### 2.1 实例化

用类类型创建对象的过程叫**实例化**：

```cpp
Person p1;   // 实例化对象 p1
Person p2;   // 实例化对象 p2
```

### 2.2 对象的内存分布

- 每个对象的**成员变量**单独开辟空间；
- **成员函数**存放在公共的特殊空间（代码区），所有对象共享，不随对象存储。

> 因此：**对象的大小只与成员变量有关**（还需考虑内存对齐），与成员函数无关。

### 2.3 内存对齐

简化版对齐规则（以 VS 默认对齐数 8 为例）：

1. 第一个成员放在偏移量为 0 的位置；
2. 其他成员要对齐到「自身大小」与「默认对齐数」的**较小值**的整数倍；
3. 类（结构体）总大小为**最大对齐数**的整数倍；
4. 可通过 `#pragma pack(n)` 修改默认对齐数。

**示例：**

```cpp
struct A
{
    char c;    // 偏移 0
    int i;     // 偏移 4（对齐到 4 的整数倍）
    short s;   // 偏移 8
};             // 总大小 = 12（最大对齐数 4 的整数倍）
```

**为什么要内存对齐？**

- **硬件效率**：CPU 按固定字节读取内存，对齐后一次即可取到数据；
- **平台兼容**：部分硬件平台不支持任意地址访问；
- 本质是**用空间换时间**。

### 2.4 空类的大小：1 字节

```cpp
class Empty
{};
```

`Empty` 类的对象大小不是 0，而是 **1 字节**。开 1 字节只是为了**占位**，表示"这个对象确实存在"，使不同对象的地址彼此不同。

## 三、this 指针

类中的成员函数会隐藏一个 **this 指针**作为**第一个参数**：

```cpp
class Date
{
public:
    void Print();   // 实际是 void Print(Date* const this);
private:
    int _year;
};
```

- this 是一个指针变量，且被 const 修饰（不能修改 this 本身，即不能改变指向）；
- 函数被调用时，系统自动把**调用对象的地址**存入 this；
- 通过 this 索引到具体对象，从而区分不同对象的成员变量：

```cpp
Date d1, d2;
d1.Print();   // this = &d1
d2.Print();   // this = &d2
```

- this 存放在**栈帧**中（部分编译器放入寄存器），**不存放在对象空间里**。

## 四、面向对象三大特性

1. **封装**：将数据与操作数据的方法结合，隐藏内部细节、只暴露接口（访问限定符是主要实现手段）；
2. **继承**：复用已有类的属性和行为，形成类层次结构；
3. **多态**：同一接口，不同对象表现出不同的行为。

## 五、类的默认成员函数

用户没有显式实现、编译器会自动生成的成员函数，称为**默认成员函数**。传统默认成员函数是 6 个，C++11 又扩充 2 个，共 **8 个**：

| 序号 | 默认成员函数 | 作用 |
| --- | --- | --- |
| 1 | 默认构造函数 | 对象实例化时初始化 |
| 2 | 析构函数 | 资源清理与释放 |
| 3 | 拷贝构造函数 | 用一个对象拷贝初始化另一个对象 |
| 4 | 赋值运算符重载 | 两个已存在对象间的拷贝赋值 |
| 5 | 普通取地址运算符重载 | `operator&` |
| 6 | const 取地址运算符重载 | `operator&` 的 const 版本 |
| 7 | 移动构造函数（C++11） | 移动资源 |
| 8 | 移动赋值运算符重载（C++11） | 移动赋值 |

> 虽然编译器会自动生成，但**自动生成的并不一定符合需求**，很多场景需要自己显式书写。

### 5.1 构造函数

**作用：** 对象实例化时初始化对象，相当于 C 语言中的 Init 函数。

```cpp
class Date
{
public:
    // 构造函数：与类名相同，无返回值（不是 void）
    Date(int year, int month, int day)
    {
        _year = year;
        _month = month;
        _day = day;
    }

private:
    int _year;
    int _month;
    int _day;
};
```

**关键点：**

- 构造函数名与类名相同，**没有返回值**；
- 对象实例化时，系统**自动调用**对应构造函数；
- 构造函数可以重载，一个类可以有多个构造函数；
- 我们不写时，编译器自动生成一个**无参**构造函数（看不到函数体）；一旦显式定义了构造函数，编译器就不再自动生成；
- **无参构造 + 全缺省构造会构成函数重载，但调用 `Date d;` 时存在歧义**，二者不能同时存在；
- 记住：构造函数是**初始化（init）**，不是创建变量；对象的内存由编译器 / 运行时先开好，再调用构造函数填充，**构造函数本身不负责分配内存**。

**默认构造函数**：不传实参就能调用的构造函数，包括三种：

1. 无参构造函数；
2. 全缺省构造函数；
3. 编译器默认生成的构造函数。

> 这三种"默认构造函数"只能存在一个。

**编译器自动生成的构造对成员的处理：**

- 内置类型成员：初始化与否**没有规定**（取决于编译器，可能是随机值）；
- 自定义类型成员：**必须**调用其默认构造函数来初始化。

> **结论：只要类中有成员变量，几乎就要自己显式写构造函数。**

### 5.2 初始化列表

每个构造函数都有初始化列表，**所有成员都会走一遍初始化列表**（无论显式写不写）。

初始化列表的使用方式：以冒号开始，接着是以逗号分隔的数据成员列表，每个成员变量后面跟一个放在括号中的初始值或表达式。

```cpp
class Date
{
public:
    Date(int year, int month, int day)
        : _year(year)      // 初始化列表
        , _month(month)
        , _day(day)
    {}
};
```

**关键点：**

- 初始化列表是**初始化**，语义上相当于"定义"；
- 对象空间不是初始化列表开的：编译器 / 运行时先开好对象空间，初始化列表负责填值；
- C++11 起，成员变量声明时可直接给**缺省值**（不是赋值）：

```cpp
class Date
{
private:
    int _year = 2024;   // 声明处缺省值
    int _month = 1;
    int _day = 1;
};
```

- 初始化列表没有写到的成员，用声明处的缺省值初始化；
- 缺省值同样作用于编译器自动生成的无参构造（相当于 C++98 的优化）；
- 构造函数形参也可以带缺省值（全缺省构造）：调用时不传实参，形参取缺省值，初始化列表再按形参值初始化对应成员：

```cpp
class Date
{
public:
    // 形参带缺省值：不传实参时，year 取缺省值 2024
    Date(int year = 2024, int month = 1, int day = 1)
        : _year(year)     // 初始化列表按形参值初始化成员
        , _month(month)
        , _day(day)
    {}
};
```

- **每个成员在初始化列表中只能出现一次**；
- 初始化顺序**不是初始化列表的书写顺序**，而是**成员变量声明的顺序**。

**必须放在初始化列表（或声明处给缺省值）的成员：**

1. const 成员；
2. 引用成员；
3. 没有默认构造函数的自定义类型成员。

否则编译报错。

**初始化规则总结：**

| 成员情况 | 初始化结果 |
| --- | --- |
| 显式写在初始化列表 | 按初始化列表初始化 |
| 声明处有缺省值 | 按缺省值初始化 |
| 内置类型、无缺省值 | 随机值（看编译器，无固定规定） |
| 自定义类型、无缺省值 | 调用其默认构造函数 |
| const / 引用 / 无默认构造的自定义类型且无缺省值 | **编译报错** |

> **建议：尽量使用初始化列表初始化成员**，否则内置类型可能得到随机值。

### 5.3 析构函数

**作用：** 完成对象**资源**的清理和释放，相当于 C 语言中的 Destroy 函数。

```cpp
class Stack
{
public:
    ~Stack()   // 类名前面加 ~，无参无返回值
    {
        free(_a);
    }

private:
    int* _a;
};
```

**关键点：**

- 析构函数的操作目标是**资源**，不是对象本身。局部对象生命周期结束、栈帧销毁即可，不需要"析构函数去销毁对象"；
- 对象生命周期结束时，系统**自动调用**析构函数；
- 一个类**只能有一个**析构函数；未显式定义时，编译器自动生成默认析构函数；
- 默认析构函数：对**内置类型成员不做处理**；对**自定义类型成员自动调用它的析构函数**；
- 无论自己写不写析构，自定义类型成员都会自动调用对应的析构函数；
- **没有申请资源（堆空间）的类不需要写析构**，直接用编译器默认生成的即可；**申请了资源的类必须自己写**，否则会造成资源泄漏；
- 同一局部域的多个对象，**后定义的对象先析构**（即生命周期先结束的对象先析构）；
- 析构函数名是在类名前加字符 `~`，无参数、无返回值。编译器默认生成的析构函数体为空，会**逆序**处理成员变量：对内置类型什么都不做（但内置指针指向的堆空间如果不管就会占用资源，所以指针成员需要自己写清理），对自定义类型成员自动调用其对应的析构函数（自定义类型的析构函数需要自己写），如果有继承，还会接着调用父类的析构函数。

### 5.4 拷贝构造函数

拷贝构造函数是**构造函数的重载**，用于用一个对象拷贝初始化另一个对象。

```cpp
class Person
{
public:
    // 第一个参数必须是类类型对象的引用（一般 const 修饰）
    Person(const Person& p)
    {
        _name = p._name;
        _age = p._age;
    }

private:
    char* _name;
    int _age;
};
```

**关键点：**

- **第一个参数必须是类类型对象的引用**（一般加 const）。传值方式编译器直接报错——语法上会引发**无穷递归**：`Person(Person p)` 的传值形参要拷贝构造，拷贝构造又要传值……无限循环；
- 可以有后续参数，但后续参数**必须都有缺省值**，否则不是拷贝构造；
- C++ 规定：**传值传参**的函数，进入函数体之前会先调用一次拷贝构造函数，所以传值传参一共会调用拷贝构造函数和函数本身两个函数。为避免额外拷贝，**传参建议传对象的引用**；
- **传值返回**会产生一个临时对象并调用拷贝构造函数。为避免拷贝，可以**传引用返回**：返回的是返回对象的引用，没有产生拷贝。但**如果返回对象是当前函数的局部对象，函数结束即销毁，这个引用就成了"野引用"（类似野指针）**。只有返回对象在函数结束后仍然存在，才能用引用返回；
- 没有显式写拷贝构造函数时，编译器会自动生成一个。自动生成的拷贝构造对内置类型和自定义类型都有作用：对内置类型成员进行**浅拷贝**（逐字节复制到新空间），对自定义类型成员调用它的拷贝构造；
- **浅拷贝的问题**：对象成员有指针指向堆资源时，两个对象的指针指向同一块地址，生命周期结束时各自调用一次析构函数，第一次析构已经释放该地址，第二次析构就会失败（double free）→ **必须自己写深拷贝**（对指向的资源也进行拷贝）；
- **小技巧：一个类如果显式实现了析构并释放资源，那么大概率也需要显式写拷贝构造**。

拷贝构造的两种书写形式，`p3` 和 `p2` 都不需要提前声明（创建、开空间），编译器会自动开好：

```cpp
Person p1;
Person p3(p1);    // 写法一：拷贝构造
Person p2 = p1;   // 写法二：拷贝构造（不是赋值！）
```

### 5.5 赋值运算符重载

赋值运算符重载是默认成员函数，用于完成**两个已经存在**的对象之间的拷贝赋值。

> 注意与拷贝构造区分：拷贝构造用于"用一个对象拷贝初始化另一个**新创建**的对象"；赋值用于**两个都已存在**的对象之间，赋值运算符重载要求两个对象都提前声明好了。

```cpp
Person p1;
Person p2;
p2 = p1;   // 赋值运算符重载
```

**关键点：**

- **必须重载为类的成员函数**；
- 参数建议传类类型对象的**引用**（传值会先拷贝构造出一个临时对象，效率低）；
- 返回值建议传**引用**（返回 `*this` 解引用），方便连续赋值：`a = b = c;`；
- 没有显式实现时，编译器自动生成默认赋值运算符重载，行为与默认拷贝构造类似：内置类型浅拷贝（逐字节），自定义类型调用它的赋值重载；
- 默认的浅拷贝对**指向资源的对象**（即对象成员有指针）不符合需求，需要自己实现**深拷贝**（对指向的资源也进行拷贝）；
- **小技巧：显式实现了析构的类，大概率需要显式写赋值运算符重载**。

### 5.6 取地址运算符重载

```cpp
class Date
{
public:
    Date* operator&() { return this; }                  // 普通取地址
    const Date* operator&() const { return this; }      // const 取地址
};
```

一般这两个函数编译器自动生成的**完全够用**，不需要显式实现。特殊场景（比如不想让别人取到当前对象的地址）可以自己实现，胡乱返回一个地址。

## 六、运算符重载

运算符用于类类型对象时，通过**运算符重载**（operator 函数）定义规则：

```cpp
bool operator==(const Date& d1, const Date& d2)
{
    return d1._year == d2._year
        && d1._month == d2._month
        && d1._day == d2._day;
}
```

**规则：**

- 函数名 = `operator` + 运算符，如 `operator==`；
- **至少有一个类类型参数**：单目运算符一个参数，双目运算符两个参数；
- 第一个参数是**左侧**运算对象，第二个是**右侧**；
- `operator==(x1, x2)` 与 `x1 == x2` 是等价的两种表示形式，其中 x1、x2 是类类型对象；
- 只能重载语法中**已经存在**的运算符，不能自创运算符；
- 有 **5 个运算符不能被重载**：`::`（域限定符）、`sizeof`、`?:`（三目运算符）、`.`（点成员）、`.*`（点星）；
- 运算符重载函数的**返回值类型根据实际规则自行确定**；
- 运算符重载函数也遵循一般规律：传值传参多调拷贝构造，传引用提升效率。

### 6.1 重载为成员函数

运算符重载函数放到类里成为成员函数后，this 指针隐式成为第一个参数：双目只显式传一个参数，单目不传参。

```cpp
class Date
{
public:
    bool operator==(const Date& d)   // 隐式 this + 显式 d
    {
        return _year == d._year;
    }
};
```

**优势：** 成员函数可以直接访问私有成员，这是最优解。

### 6.2 前置 ++ 与后置 ++

前置和后置重载函数名都是 `operator++`，无法区分。C++ 规定：**后置 ++ 增加一个 int 形参**，与前置构成函数重载：

```cpp
Date& operator++()        // 前置 ++
{
    _day += 1;
    return *this;
}

Date operator++(int)      // 后置 ++（多一个 int 占位参数）
{
    Date tmp(*this);
    _day += 1;
    return tmp;
}
```

### 6.3 重载 << 和 >>：必须重载为全局函数

`<<` 和 `>>` 需要重载为**全局函数**。因为重载为成员函数时，this 指针会抢占第一个形参位置（左侧运算对象），调用就变成 `对象 << cout`，不符合使用习惯和可读性。

重载为全局函数时，把 `ostream` / `istream` 放到第一个形参位置，第二个形参放类类型对象：

```cpp
class Date
{
    // 全局函数要访问私有成员，需要声明友元
    friend ostream& operator<<(ostream& out, const Date& d);

public:
    // 成员函数……
};

ostream& operator<<(ostream& out, const Date& d)
{
    out << d._year << "-" << d._month << "-" << d._day;
    return out;
}
```

## 七、const 成员函数

将 const 修饰的成员函数称为 **const 成员函数**，const 放在**成员函数参数列表的后面**：

```cpp
void Print() const;
```

注意：这里讨论的是成员函数。**非成员函数没有隐含的 this 指针，不存在这种 const 修饰方式**。

- const 实际修饰的是隐含的 this 指针：`Date* const this` → `const Date* const this`；
- 表明该成员函数内**不能修改任何成员变量**；
- 需要修改成员变量的函数不能加 const；**不修改成员变量的函数建议都加 const**（无论对象是否被 const 修饰都可以调用）；
- 好处：const 对象和非 const 对象都能调用，同时提供编译期检查，保证权限的稳定传递。

## 八、类型转换

### 8.1 内置类型 → 类类型（隐式转换）

C++ 的隐式类型转换依靠构造函数实现，需要提供以内置类型为参数的构造函数：

```cpp
class Date
{
public:
    Date(int year)   // 支持内置类型 → Date
        : _year(year)
    {}

private:
    int _year;
};

Date d = 2024;   // 隐式类型转换
```

在构造函数前加 **explicit**，就不再支持隐式类型转换：

```cpp
explicit Date(int year);

Date d = 2024;   // 报错，必须显式构造：Date d(2024);
```

### 8.2 类类型对象之间互相转换

类类型对象之间也可以隐式转换，需要相应的构造函数支持。

## 九、static 静态成员

### 9.1 静态成员变量

- **static 修饰的静态成员变量，必须在类外进行初始化**；
- 静态成员变量为**所有类对象所共享**，不属于某个具体的对象，不存在于对象空间中，其空间开在**静态区**；
- 静态成员受访问限定符限制，也受类域限制；它不属于任何对象，但生命周期是全局的，依然是类的成员。

```cpp
class Counter
{
public:
    static int _count;   // 静态成员变量：类内声明
};

int Counter::_count = 0; // 静态成员变量：必须在类外初始化

int main()
{
    Counter c1;
    Counter c2;

    Counter::_count = 3;   // 方式一：类名::静态成员
    c1._count = 5;         // 方式二：对象.静态成员（public 时）

    return 0;
}
```

> 注意：`c1._count = 5;` 和 `Counter::_count = 3;` 修改的是同一个共享变量。

- **静态成员不能在声明位置给缺省值初始化**。因为缺省值用于构造函数的初始化列表，而静态成员不属于某个具体对象，不会走初始化列表：

```cpp
class Counter
{
public:
    static int _count = 0;   // 错误：静态成员不能在声明处给缺省值
};
```

### 9.2 静态成员函数

- **static 修饰的静态成员函数没有 this 指针**，因此可以访问其他静态成员，但**不能访问非静态成员**（因为没有 this 指针去定位具体对象）；
- 非静态成员函数可以访问静态和非静态的任意成员变量；
- 访问静态成员函数同样有两种方式：`类名::静态成员` 或 `对象.静态成员`。

```cpp
class Counter
{
public:
    static void Show()   // 静态成员函数：没有 this 指针
    {
        cout << _count << endl;   // 只能访问静态成员
    }

    static int _count;
};
```

### 9.3 静态成员的补充说明

- 静态修饰的函数或变量，在**程序运行到定义所在的那一行**时才进行初始化和开始执行，不存在"提前生效"的说法；
- **局部静态变量**的生命周期也是全局的。程序结束时按逆序析构：局部静态变量先析构，普通全局变量（一般声明在前）后析构。

## 十、友元函数

- 友元**突破了封装**。友元分为**友元函数**和**友元类**两种，在函数声明或类声明前加 `friend`，并把友元声明放到某个类里；
- 外部友元函数可以访问类的 private 成员。**注意：友元函数不是类的成员函数**；
- 友元函数可以在类的任何位置声明，**不受访问限定符的限制**；
- 一个友元函数可以同时作为多个类的友元。

```cpp
class Date
{
    friend void Show(const Date& d);   // 友元函数声明：可放在类内任意位置

public:
    Date(int year = 2024)
        : _year(year)
    {}

private:
    int _year;
};

void Show(const Date& d)   // 注意：友元函数不是类的成员函数
{
    cout << d._year << endl;   // 可以访问 private 成员
}

int main()
{
    Date d;
    Show(d);
    return 0;
}
```

**友元关系的特点：**

- **单向的**：如果 A 类是 B 类的友元，A 可以访问 B 的成员，但 B 不能反过来访问 A 的成员（A 不允许 B 成为自己的友元）；
- **不传递的**：如果 A 是 B 的友元、B 是 C 的友元，那么 A 和 C 不是友元——"朋友的朋友不是我的朋友"；
- 友元**增加了类之间的耦合度，破坏了封装**，所以应**精简使用**。

**友元类：**

友元类的所有成员函数都是另一个类的友元函数，可以访问另一个类的所有私有（保护）成员。

```cpp
class A
{
    friend class B;   // 声明 B 是 A 的友元类

private:
    int _a;
};

class B
{
public:
    void Show(const A& a)
    {
        cout << a._a << endl;   // B 的成员函数可以访问 A 的私有成员
    }
};
```

## 十一、内部类

- 如果一个类定义在另一个类的内部，这个类就叫**内部类**；
- 内部类是一个**独立的类**。与定义在全局的类相比，它只是受外部类**类域**和**访问限定符**的限制，所以外部类定义的对象中不包含内部类（对象内存里没有内部类）；
- **内部类默认是外部类的友元类**；
- 当 A 类与 B 类紧密关联、A 实现出来主要就是给 B 使用时，可以考虑把 A 设计为 B 的内部类。内部类实际上是一种**封装**。

```cpp
class Outer
{
public:
    class Inner   // 内部类：定义在另一个类的内部
    {
    public:
        void Func()
        {
            // 内部类默认是外部类的友元类
            // 可以直接访问外部类的私有成员
        }
    };
};
```

## 十二、匿名对象

- 用 `类型(实参)` 定义出来的对象叫**匿名对象**；用 `类型 对象名(实参)` 定义出来的叫**有名对象**；
- 匿名对象的**生命周期只在当前这一行**，是一次性使用的，使用完就销毁；
- 用 **const 引用**接收匿名对象，可以**延长其生命周期**。

```cpp
Date(2024, 10, 1);   // 匿名对象：生命周期只在当前这一行
Date d(2024, 10, 1); // 有名对象

const Date& r = Date(2024, 10, 1);   // const 引用可以延长匿名对象的生命周期
```

## 十三、对象拷贝时的编译器优化

- 现代编译器会尽可能提高程序效率，在**不影响正确性**的前提下，尽量减少传参和传返回值过程中**可以省略的拷贝**；
- 当前主流的较新编译器，会对**同一表达式步骤中的连续拷贝**进行合并优化；
- 有些更新、更"激进"的编译器，还会进行**跨行、跨表达式**的合并优化。

```cpp
Date d = Date(2024, 10, 1);   // 一次构造 + 一次拷贝，编译器可能合并优化为一次构造
```

## 十四、综合示例：Date 类

综合运用上述知识的一个完整 Date 类：

```cpp
#include <iostream>
using namespace std;

class Date
{
    friend ostream& operator<<(ostream& out, const Date& d);

public:
    // 构造函数：全缺省（也是默认构造函数）
    Date(int year = 2024, int month = 1, int day = 1)
        : _year(year)
        , _month(month)
        , _day(day)
    {}

    // 拷贝构造
    Date(const Date& d)
        : _year(d._year)
        , _month(d._month)
        , _day(d._day)
    {}

    // 析构函数（无资源时用默认即可，这里显式写出来演示）
    ~Date()
    {}

    // 赋值运算符重载
    Date& operator=(const Date& d)
    {
        if (this != &d)   // 防止自赋值
        {
            _year = d._year;
            _month = d._month;
            _day = d._day;
        }
        return *this;     // 传引用返回，支持连续赋值
    }

    // const 成员函数
    void Print() const
    {
        cout << _year << "-" << _month << "-" << _day << endl;
    }

    // 前置 ++
    Date& operator++()
    {
        _day += 1;
        return *this;
    }

    // 后置 ++
    Date operator++(int)
    {
        Date tmp(*this);
        _day += 1;
        return tmp;
    }

private:
    int _year;
    int _month;
    int _day;
};

// 全局 << 重载（友元函数）
ostream& operator<<(ostream& out, const Date& d)
{
    out << d._year << "-" << d._month << "-" << d._day;
    return out;
}

int main()
{
    Date d1(2024, 10, 1);
    Date d2(d1);        // 拷贝构造
    Date d3 = d1;       // 拷贝构造
    d3 = d2;            // 赋值运算符重载

    ++d1;               // 前置 ++
    d1++;               // 后置 ++

    cout << d1 << endl; // operator<<
    d1.Print();         // const 成员函数

    return 0;
}
```

## 十五、总结

1. **类**是 C++ 自定义类型，访问限定符（public / private / protected）实现封装；struct 与 class 的区别仅在默认访问权限。
2. 对象大小只取决于成员变量（考虑内存对齐）；空类大小为 1 字节（占位）。
3. 成员函数隐藏 **this 指针**（const 修饰），存在栈帧 / 寄存器，不在对象空间。
4. 默认成员函数共 **8 个**：构造、析构、拷贝构造、赋值重载、两个取地址重载，以及 C++11 新增的移动构造、移动赋值。
5. **构造函数**负责初始化，尽量使用**初始化列表**；const / 引用 / 无默认构造的成员必须放初始化列表。
6. **析构函数**负责资源释放，申请了资源必须自己写。
7. **拷贝构造 / 赋值重载**对指针成员必须深拷贝；显式写了析构的类大概率也要显式写它们。
8. **运算符重载**：`<<` / `>>` 重载为全局函数；后置 ++ 用 int 占位参数区分；5 个运算符不可重载。
9. **const 成员函数**修饰隐含的 this，不修改成员的建议都加 const。
10. 隐式类型转换依靠构造函数实现，**explicit** 可禁止隐式转换。
11. **static 成员**属于类、不属于对象，必须在类外初始化；静态成员函数没有 this 指针，只能访问静态成员。
12. **友元**突破封装：关系单向、不传递，应精简使用。
13. **内部类**是定义在类内部的独立类，默认是外部类的友元类，本质是一种封装。
14. **匿名对象**生命周期只在当前一行，const 引用可延长其生命周期。
15. 现代编译器会**合并优化**对象拷贝过程中的连续拷贝，提高效率。
